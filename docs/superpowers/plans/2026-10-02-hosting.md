# Hosting on Fly.io Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Run the todo app on Fly.io at `https://mytodo.fly.dev`, with common operations as mise tasks.

**Architecture:** A small Dockerfile (built by Fly's remote builder), `fly.toml` for one 256 MB machine with a 1 GB volume, `mise.toml` tasks that wrap flyctl, and `docs/deploy.md`. One app change: the limit of parallel password checks goes from 4 to 2. A Go test keeps the three config files consistent.

**Tech Stack:** Go 1.27.1, Fly.io (flyctl via mise), distroless static image, mise 2026.4.18.

**Spec:** `docs/superpowers/specs/2026-10-02-hosting-design.md` (approved).

**Execution:** Native, then one whole-branch review by a fresh reviewer. Worktree `~/claude-personal/todo-worktrees/hosting`, branch `hosting` (already created from `main` 13b98d5). One commit per task (Co-Authored-By line). No push. No flyctl command that needs a login runs during execution; the user runs those after the merge.

## Global Constraints

- App name `mytodo`, region `waw`, volume `todo_data` at `/data`, database `/data/todo.db`, port 8080, `-trust-proxy` on.
- Machine 256 MB, shared CPU, swap 256 MB. One machine only (`--ha=false`).
- Plain `go …`; check `go test`'s own exit code.
- No UI changes.

## Review Focus

1. The three config files name different ports, paths, or app names. → Task 2 `TestDeployConfigMatches`.
2. `.dockerignore` removes a file the build needs (templates and static files are embedded from `internal/web`). → Task 2 Step 5: build from a copy that respects `.dockerignore`.
3. The binary needs a C library that distroless does not have. → Task 2 Step 5: `CGO_ENABLED=0` build, `file` says "statically linked", the binary starts with a temp database.
4. A username that starts with `-` breaks the mise user tasks. → Task 2: `--` before the name; Step 6 runs the same argument list locally.
5. The parallel password checks need more memory than the machine has. → Task 1 `TestParallelHashesFitSmallMachine`.

## Ruling made while planning (differs from the spec)

`fly:stop` / `fly:start` are left out. `fly scale count 0` destroys the machine, and the volume would then need to be attached to a new machine by hand. Auto-stop already makes an idle machine cost nothing except the volume. Task 2 updates spec section 8 to match. Cost if wrong: the user runs `fly scale count 0` by hand (documented in `docs/deploy.md`, with the warning).

import (

// The Dockerfile, fly.toml and mise.toml must name the same port, paths and app.
func TestDeployConfigMatches(t *testing.T) {
	read := func(name string) string {
		b, err := os.ReadFile("../../" + name)
		if err != nil {
			t.Fatalf("read %s: %v", name, err)
		}
		return string(b)
	}
	find := func(text, pattern, what string) string {
		m := regexp.MustCompile(pattern).FindStringSubmatch(text)
		if m == nil {
			t.Fatalf("%s not found (pattern %s)", what, pattern)
		}
		return m[1]
	}
	docker, fly, mise := read("Dockerfile"), read("fly.toml"), read("mise.toml")

	port := find(docker, `"-addr", ":(\d+)"`, "Dockerfile -addr port")
	db := find(docker, `"-db", "([^"]+)"`, "Dockerfile -db path")
	if !strings.Contains(docker, `"-trust-proxy"`) {
		t.Error("Dockerfile does not start the app with -trust-proxy")
	}
	if p := find(fly, `internal_port = (\d+)`, "fly.toml internal_port"); p != port {
		t.Errorf("fly.toml internal_port = %s, Dockerfile -addr port = %s", p, port)
	}
	if mount := find(fly, `destination = "([^"]+)"`, "fly.toml mount destination"); !strings.HasPrefix(db, mount+"/") {
		t.Errorf("database %s is not on the volume at %s", db, mount)
	}
	if m := find(mise, `TODO_DB = "([^"]+)"`, "mise.toml TODO_DB"); m != db {
		t.Errorf("mise.toml TODO_DB = %s, Dockerfile -db = %s", m, db)
	}
	if a, b := find(fly, `(?m)^app = "([^"]+)"`, "fly.toml app"), find(mise, `FLY_APP = "([^"]+)"`, "mise.toml FLY_APP"); a != b {
		t.Errorf("fly.toml app = %s, mise.toml FLY_APP = %s", a, b)
	}
}

- [ ] **Step 2: `Dockerfile`**

```dockerfile
# Fly's remote builder runs this file (`mise run fly:deploy`); no local Docker is needed.
FROM golang:1.27.1 AS build
WORKDIR /src
COPY go.mod go.sum ./
RUN go mod download
COPY . .
# The SQLite driver is pure Go, so the binary is static and needs no C library.
RUN CGO_ENABLED=0 go build -trimpath -ldflags="-s -w" -o /todo ./cmd/todo

FROM gcr.io/distroless/static-debian12
COPY --from=build /todo /todo
ENTRYPOINT ["/todo"]
CMD ["-addr", ":8080", "-db", "/data/todo.db", "-trust-proxy"]
```

```toml
# Fly.io configuration. Common commands are mise tasks (mise.toml); see docs/deploy.md.
app = "mytodo"
primary_region = "waw"
kill_signal = "SIGTERM"
kill_timeout = "10s"
swap_size_mb = 256

# The database lives on this volume. Fly takes a snapshot every day and keeps 5.
[mounts]
  source = "todo_data"
  destination = "/data"
  snapshot_retention = 5

[http_service]
  internal_port = 8080
  force_https = true
  auto_stop_machines = "stop"
  auto_start_machines = true
  min_machines_running = 0

  [[http_service.checks]]
    method = "GET"
    path = "/login"
    interval = "30s"
    timeout = "5s"
    grace_period = "10s"

# Two parallel password checks (64 MiB each) fit in 256 MB.
[[vm]]
  memory = "256mb"
  cpu_kind = "shared"
  cpus = 1
```

- [ ] **Step 4: `mise.toml`**

```toml
# Common Fly.io operations. Run `mise install` once, then `mise run <task>`.
# See docs/deploy.md.
[tools]
flyctl = "latest"
jq = "latest"

[env]
FLY_APP = "mytodo"          # flyctl reads FLY_APP; fly.toml names the same app
TODO_DB = "/data/todo.db"   # database path on the server (see Dockerfile)

[tasks."fly:setup"]
description = "Create the Fly app and its 1 GB volume (run once)"
run = [
  "fly apps create $FLY_APP",
  "fly volumes create todo_data --size 1 --region waw --yes",
]

[tasks."fly:build"]
description = "Build the image on Fly without deploying it"
run = "fly deploy --build-only"

[tasks."fly:deploy"]
description = "Deploy the current code to the one machine"
run = "fly deploy --ha=false"

[tasks."fly:status"]
description = "Show the app and machine state"
run = "fly status"

[tasks."fly:logs"]
description = "Show the app logs"
run = "fly logs"

[tasks."fly:open"]
description = "Open the app in the browser"
run = "fly apps open"

[tasks."fly:users"]
description = "List the users"
run = 'fly ssh console -C "/todo users list -db $TODO_DB"'

[tasks."fly:reset-password"]
description = "Set a new random password for a user and print it"
usage = 'arg "<name>" help="Username"'
run = 'fly ssh console -C "/todo users reset-password -db $TODO_DB -- ${usage_name}"'

[tasks."fly:delete-user"]
description = "Delete a user and all their items (asks first)"
usage = 'arg "<name>" help="Username"'
confirm = "Delete this user and all their items?"
run = 'fly ssh console -C "/todo users delete -yes -db $TODO_DB -- ${usage_name}"'

[tasks."fly:snapshots"]
description = "List the daily snapshots of the data volume"
run = 'fly volumes snapshots list "$(fly volumes list --json | jq -r ".[0].id")"'
```

### Task 3: Deploy guide

**Files:** create `docs/deploy.md`.

- [ ] **Step 1: Write `docs/deploy.md`** with these sections and exact commands:

1. **What runs where** — one sentence each: Fly machine `mytodo` in Warsaw, 256 MB, stops when idle; volume `todo_data` (1 GB) holds `/data/todo.db`; daily snapshots kept 5 days; address `https://mytodo.fly.dev`.
2. **First setup** — `mise trust && mise install`; `fly auth login`; `mise run fly:setup` (if the name `mytodo` is taken, change it in `fly.toml` and `mise.toml`); `mise run fly:build`; `mise run fly:deploy`; `mise run fly:open`, then sign up.
3. **Check the proxy rule once** — enter a wrong password 6 times; `mise run fly:logs` must show `login blocked ... ip=<your public IP>`. If it shows a Fly address, all users share one limit: stop and report.
4. **Daily use** — deploy a new version (`mise run fly:deploy`), logs, status.
5. **Users** — `mise run fly:users`, `mise run fly:reset-password <name>`, `mise run fly:delete-user <name>`.
6. **Snapshots and restore** — `mise run fly:snapshots`; restore: `fly volumes create todo_data --snapshot-id <id> --region waw --size 1 --yes`, then `fly machine clone <machine id> --attach-volume <new volume id>:/data`, check the app, then `fly machine destroy <old machine id> --force` and `fly volumes destroy <old volume id>`; link https://fly.io/docs/volumes/snapshots/.
7. **Costs** — machine about USD 2/month while running, nothing while stopped; volume about USD 0.15/month always; snapshots may be billed per GB (check Fly's pricing page). To take the app off the internet: `fly scale count 0 --yes` — this destroys the machine; to come back, `mise run fly:deploy` creates a new machine, which needs the volume attached (see 6).
8. **Grow the volume** — `fly volumes extend <id> --size 2` (cannot shrink).
